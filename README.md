# 전략지도 데이터 검토 창구 — 웹앱

검토자(claude.ai 계정 없음)가 **웹 주소 + 본인 검토자 코드**로 들어와 검토 의견을 저장하는 Next.js 앱입니다.
화면은 검토 창구(아티팩트)와 같고, 검토 기록은 Supabase `nigt-data-review`에 저장됩니다.

- 화면 파일(`public/review.html`, 검토 자료 포함)은 **저장소에 없습니다.** Vercel 빌드 때 Supabase에서 받아 옵니다(`scripts/fetch_page.mjs`, sha256 확인 · APP_SECRET 필요).
- 비밀값 · 검토 자료 · 검토자 명단은 저장소에 없습니다. 비밀값은 Vercel 환경변수로만 넣습니다.

## 로그인 코드
| 코드 | 할 수 있는 것 |
|---|---|
| 검토자 코드(8자리 숫자 + 이니셜 소문자) | 이름 고정 · **담당 데이터 요소만** 입력·저장(서버도 403으로 막음) |
| 관리자 코드(`ADMIN_CODE`) | 전체 입력 · 요소 판정 · 「관리」 탭(담당 배정 변경 · 검토자 코드 목록) |
| 공용 접속 코드(`ACCESS_CODE`) | 보기 전용(저장 불가) |

- 숫자 8자리는 서버 비밀값으로 검토자마다 계산하며 어디에도 저장하지 않습니다(`lib/auth.js`). 코드를 모두 바꾸려면 Supabase settings의 `code_ver`를 올립니다(재배포 필요 없음).
- 담당 배정 변경(`config` 문서)은 관리자 세션만 저장할 수 있습니다(`app/api/docs`).

## 🤖 AI 자동 답변 · 🔔 관리자 휴대폰 알림 (10/1)
검토자가 채팅에 질문을 올리면 관리자(정유정 · 명단의 관리자) 휴대폰에 알림이 가고, 필요하면 AI(Claude)가 관리자 말투로 먼저 답합니다.

| 상황 | 하는 일 |
|---|---|
| 검토자가 질문을 올림(「❓ 질문」 표시 · 물음표 · 「~나요/~까요」 등) | 관리자 기기에 「❓ 새 질문」 알림 |
| **부재 중** 켬 | 질문이 오자마자 AI가 답 |
| **기다렸다 답** 켬(기본 켬 · 10분, 5~60분) | 질문 뒤 그 시간 동안 관리자 글이 없으면 AI가 답 — 관리자가 답글을 달았거나 질문 뒤에 채팅에 글을 썼으면 답하지 않음 |
| 관리자가 정해야 하는 질문(판정 대신 정하기 · 기준 예외 · 용역사 요청 · 일정 · 담당 변경 · 플랫폼 수정, 파일을 열어 봐야 아는 것, 안내에 근거가 없는 것) | AI는 짧은 보류 답만(「…확인하고 답드릴게요!」) + 관리자에게 「⏸ 확인이 필요한 질문」 알림 |
| 인사 · 감사 · 혼잣말 · 이미 해결된 대화 | 답하지 않음 |
| 관리자가 질문의 「🤖 AI 답 만들기」 | 초안만 돌려줌(채팅에 올리지 않음) — 고쳐서 보통 채팅으로 보냄 |

- 자동 답변은 관리자 이름으로 올라가지만 데이터에 `tag: 'ai'`(+ `ai: {kind: 'answer'|'hold', model}` · `re: <질문 id>`)가 붙어 화면에 「🤖 자동 답변」으로 보입니다. 화면(검토자 · 관리자)은 `tag: 'ai'` 글을 저장할 수 없습니다(서버만 씀). 관리자는 자동 답변을 지울 수 있습니다.
- 같은 질문에는 한 번만 답합니다(서버 여러 대가 동시에 봐도 — kv `ai_done:<질문 id>`를 먼저 차지한 쪽만). AI 오류는 1분 뒤 다시, 세 번 실패하면 멈추고 「⚠️ 자동 답변 실패」 알림. 한 시간 한도(`AI_MAX_PER_HOUR`)를 넘으면 「⚠️ 자동 답변 한도」 알림(한 시간에 한 번) — 남은 질문은 다음 시간에.
- 개인정보: AI에는 사람 이름을 보내지 않습니다(글쓴이는 관리자 · 검토자1 · 검토자2…, 글 속 이름도 바꿔 보냄). 글 내용 · 키는 서버 로그에 남기지 않습니다. 키는 Vercel 환경변수에만 둡니다.
- AI가 참고하는 자료 = 비공개 파일 `ai_ctx.json`(말투 · 예시 · 검토 안내 · 용어 · FAQ · 요소 카드 — 화면 파일처럼 Supabase `nr_review.assets`에 올림, 10분마다 다시 읽음). 없으면 AI는 근거가 없으니 대부분 보류 답을 냅니다.
- 휴대폰 알림: 관리자가 화면에서 알림을 켜면 그 기기가 등록됩니다(최대 10대 · 없어진 기기는 자동으로 빠짐). **아이폰 · 아이패드는 「홈 화면에 추가」한 앱에서만** 알림을 받을 수 있습니다(iOS 16.4 이상). 알림 서명 키(VAPID)는 처음 쓸 때 서버가 만들어 DB에 둡니다.
- 설정 · 알림 기기 · 서명 키는 모두가 읽는 `config` 컬렉션이 아니라 서버 전용 표 `nr_review.kv`에 둡니다.

**켜는 순서**
1. Supabase SQL Editor(nigt-data-review)에서 `supabase/migration_ai.sql`을 한 번 실행(여러 번 실행해도 됨 · 되돌리기는 파일 맨 아래). — 10/1 적용함
2. Vercel 환경변수 `ANTHROPIC_API_KEY`를 넣고(선택: `AI_MODEL` · `AI_MAX_PER_HOUR` · `VAPID_SUBJECT`) **Redeploy**.
3. `ai_ctx.json`을 Supabase에 올림(화면 파일과 같은 방법 — settings `asset_sha256:ai_ctx.json`에 sha256). — 10/1 올림
4. 관리자 화면에서 휴대폰 알림을 켜고 「시험 알림」으로 확인.

키가 없어도 휴대폰 알림은 동작합니다(자동 답변 · 초안만 꺼짐).
